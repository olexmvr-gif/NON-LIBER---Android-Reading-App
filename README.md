# NON·LIBER

**NON·LIBER** is a free, local-first Android e-book reader and personal reading library.

It is built for people who want strong control over their books without accounts, advertising, or a cloud service sitting between the reader and the file.

## What it reads

- EPUB
- FB2 / FB2.zip
- DRM-free MOBI / PRC
- DRM-free AZW / AZW3
- Markdown
- PDF

Some formats have different capabilities. For example, PDF uses its own fixed-layout reader, while EPUB/FB2/Kindle-family books use the reflowable Reader.

## Basic use

1. Download the current public-test APK from **Releases** when a build is available.
2. Install it on an Android device.
3. Open NON·LIBER and use **Import** to add your own books or documents.
4. Use **Library** for normal organisation, sorting, filtering and metadata.
5. Use **Artefact** when you want to build a more personal modular library from rows, shelves, collections, authors, genres and other views.
6. Open a publication to enter the **Reader**, where you can change typography, search, bookmark, highlight, underline, strike out text, add comments and keep your reading position.
7. **Scriptum** is the Markdown / Journal / Document side of NON·LIBER, with writing, Notes and Vault organisation.

Your imported publications and app-owned metadata remain local to the device unless you explicitly export, back up or sync them.

## Public testing

NON·LIBER is in active development. Phone use is well tested, but broader testing across manufacturers, Android versions, tablets, unusual display sizes and different document collections is very welcome.

If you find a problem, please open a GitHub Issue and include, where possible:

- device model;
- Android version;
- NON·LIBER version;
- publication format;
- what you expected;
- what actually happened;
- screenshot or short screen recording.

## Current platform notes

The current v0.6.0.0.7 public-test build targets Android 8.0 / API 26 and later. Tablet compatibility needs broader physical testing.
